# Realtime Translate

## How to Run
**1️⃣ สร้าง Virtual Environment**
```bash
python3 -m venv venv
```
- mac / linux
```bash
source venv/bin/activate
```
- windows
```bash
venv\Scripts\activate
```

**2️⃣ ติดตั้ง dependencies**
```bash
pip install -r requirements.txt
```

**3️⃣ Run โปรแกรม**
```bash
python main.py
```
หรือ
```bash
python3 main.py
```
